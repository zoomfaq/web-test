# web-test

Ниже — короткий чек-лист, чтобы создать новый Pull Request.

## Как создать новый PR
1. Откройте репозиторий на GitHub.
2. Переключитесь на нужную ветку.
3. Нажмите **Compare & pull request**.
4. Заполните заголовок и описание.
5. Нажмите **Create pull request**.

## Публикация на GitHub Pages
Проект хранит статические страницы и готов для публикации через GitHub Pages.
